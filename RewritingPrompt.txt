 Backend ove aplikacije se nalazi u folderu api, i trenutno je napisan u c#. Tvoj zadatak je da prepises ceo taj backend u javi prilikom cega sve funkcionalnosti moraju ostati ocuvane. Pre nego sto pocnes pisati bilo sta, procitaj i
  analiziraj sve fajlove u api folderu, ali gledaj da ne potrosis previse tokena na ovo.Glavne smernice: Novi backend stavi u root direktorijuma u folder api_java. Backend treba da bude napisan u Javi 21 koristeci Spring i Spring Boot.
  Controller sloj treba da koristi Spring Web REST controllers, za ORM treba da se koristi Spring Data JPA (Hibernate). Za API autentifikaciju ces koristiti Spring Security + JWT(jjwt). Sto se tice zamene za Hangfire i pozadinske
  poslove (sessionCleanupJob), koristi ili JobRunr ili @ Scheduled anotaciju, stagod ti mislis da je bolje. Za validaciju ulaznih podataka koristi Jakarta Bean Validation. Za LiveKit integraciju koristi LiveKit Java SDK sa https://
  github.com/livekit/server-sdk-kotlin. U c# repozitorijumu se koristi UnitOfWork pattern, koji ces u javi zameniti sa Transactional anotacijama na servisnom sloju. Takodje je implementiran i GenericRepository pattern, koji ces u Javi
  zameniti sa JpaRepozitory. Apsolutno je obavezno da api specifikacija ostane ista (URL putanje, DTO klase) tako da se novi backend moze koristiti sa postojecim frontend-om. Za dependency managment koristi Maven sa pom.xml
  specifikacijom. Ne moras pisati nikakve testove.Za bazu podataka koristi PostgreSQL. Za S3-compatible skladiste koristi minio na isti nacin na koji se on koristi u c# repozitorijumu. Potrudi se da kod bude cist, prati sve Java standarde, i najvaznije od svega, radi kako treba. Napisi i dockerfile i docker compose fajlove za novi
  projekat (ne menjaj postojece, napravi nove). Isprati svaku gorenapisanu instrukciju.
